VisuGeo Maps

Aplicativo para visualização de mapas e projetos agrícolas.

Política de Privacidade

O VisuGeo Maps utiliza o login do Google para permitir a autenticação dos usuários.

Os dados utilizados dependem das funcionalidades autorizadas pelo usuário. Não solicitamos acesso a dados além dos necessários para as funcionalidades oferecidas.

Contato

Para dúvidas sobre privacidade, entre em contato com o desenvolvedor do aplicativo.
